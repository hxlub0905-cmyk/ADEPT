# 怎麼看一片區域均不均勻

> **d4t — defect**　·　Measure 段的 `Gray level`（`glv_stats`）＋
> Output 段的 `Write uniformity`（`output_uniformity`）
> 這一份是**給使用者的操作手冊**：每一格是什麼、四張圖各回答哪一句話、
> 出事了照什麼順序查。設計上的來龍去脈在
> [`docs/plans/F85-uniformity.md`](plans/F85-uniformity.md)，那一份不必讀。

---

## 0. 一分鐘上手

**最快的路是不要自己搭**：工具列 `Open recipe…` → **`one-image-uniformity`**，
然後 `Open image…` 挑你那張圖。跑一次就有四張圖。

⚠ **開起來之後先做兩件事**：

1. **`Write to` 換成完整路徑**（例 `D:\uniformity\my_field`）。出貨的檔案裡
   填的是相對路徑，那會落在**你啟動 Studio 的那個資料夾**旁邊。
2. **跑的時候要按 `Run all & write`**，不是 `Run trial` —— 見 §5。

自己搭的話五張卡：

```
                              ┌──→ [Write uniformity]   四張圖
[Load one image] ─→ [ROI] ┄┄→ [Gray level]
        └──────實線───────────→ ┘   └──→ [Write report]      defects.csv
```

（`ROI` 到 `Gray level` 那一條是**虛線**：區域走的是菱形埠。）

1. **`Open image…`** 挑一張圖（不需要 KLARF）。
2. **ROI** 卡把框鋪滿整張圖（`Find them by` = `stripes in the image`，
   `Pick` = `none`）。
3. **Gray level**：卡片**最上面**那排 `What to measure` 按
   **`Odd box out`** —— 那顆鈕會幫你把 `Boxes in the region` 設成 `each box`。
   （三顆鈕在還沒拉區域虛線之前是灰的，所以順序是**先拉線、再按鈕**。）
   然後 `How even are the boxes` 勾你要的數字。
4. **`Write uniformity`**：`Write to` 填**完整路徑**的資料夾。
5. **`Write report`**：`Write to` 填**同一個**資料夾，`What to put in the
   folder` 勾 `table` —— 數字才有 CSV 可以進 Excel。

**最重要的一句話**：所有均勻度的數字都來自 **`each box`**。
停在 `pooled` 的話那一整群框會被當成一堆像素混在一起 ——
「這幾格之間差多少」這個問題根本問不出來，而卡片上那一格會**不出現**。

## 1. 那五個數字各回答哪一句話

在 Gray level 卡的 **`How even are the boxes`** 勾選。

| 勾這個 | 得到 | 白話 | 完美的話是 |
|---|---|---|---|
| `cv_pct` | `<量>_cv_pct` | 這幾格散多開，佔平均的 % | **0** |
| `range` | `<量>_range` | 最亮那格 − 最暗那格，灰階 | 0 |
| `range_pct` | `<量>_range_pct` | ↑ 佔平均的 % | 0 |
| `slope_x` | `<量>_slope_x` | 左到右**每 100 px** 變多少 | **0** |
| `slope_y` | `<量>_slope_y` | 上到下每 100 px 變多少 | 0 |

**預設勾三個**（`cv_pct` / `slope_x` / `slope_y`）—— 「均不均勻」加
「有沒有斜掉」，兩句話就是這個問題的全部。

名字的讀法固定是 **哪一塊 → 量什麼 → 什麼統計**：
`epi_glv_median_cv_pct` ＝「epi 這群框、中位數灰階、CV %」。
**只接一個區域、一條流的時候前面那一段是空的**（`glv_median_cv_pct`）。

### ⚠ 斜率的單位是「每 100 px」，不是「每 px」

真實影像上的灰階梯度是每 px 0.00x 那種量級。報成每 px 的話，一片**明顯**
左右不均的圖，那一欄會整欄印成 `0.000` —— 讀起來是「很平」，
而且不會有任何錯誤訊息。單位欄上寫著 `gray / 100 px`，那個 100 是它的一部分。

### ⚠ 算不出來的那一格**不寫**，不是寫 0

只有一格框、或所有框擠在同一個座標上的時候，斜率**不會出現**在特徵表上。
那不是「很平」，是「這件事問不出來」—— 而一個 0 會讓你以為是前者。

## 2. 四張圖各回答哪一句話

在 `Write uniformity` 的 **`Which charts`** 勾選。四張圖的**一個點都是一格框**。

**看圖請按儀表右下角那顆 `Preview charts…`** —— 四張圖會開在自己的視窗裡，
大到讀得動，而且**不用跑整批**（選了 defect、跑過一次預覽就有）。
儀表本身留給「按下去會寫哪幾個檔」＋ 這一顆量出來的 CV／斜率。

> 那個視窗畫的**就是**會寫出去的那一張 SVG —— 同一支程式碼，一個位元組都
> 不差。所以在那裡調到滿意，寫出來就是那個樣子。

| 圖 | X 軸 | 回答 | 完美的話長什麼樣 |
|---|---|---|---|
| **Box plot** | 區域 | 這幾群各自散多開、群跟群差多少 | 盒子又扁又短 |
| **Histogram** | 灰階值 | 值怎麼散開 | 一座窄的山 |
| **Position profile** | 框中心的 X（或 Y） | **有沒有斜掉** | **一條平的線** |
| **Heat map** | 框的 (x, y) | 不均勻在**哪裡** | **一片同色** |

> **`Profile along`（左到右／上到下）只在你勾了 Position profile 的時候才
> 出現。** 沒勾那張圖的話那一格什麼都不影響，所以卡片乾脆不問。

### Position profile 上有三種線，各一個顏色

| 線 | 是什麼 |
|---|---|
| **空心點** | 一格框一個 |
| **實線**（區域色） | 同一欄的框收成一個點的平均。**讀平不平就是讀這一條** |
| **黑虛線** | 穿過每一格的最小平方線，斜率印在圖下面 |
| **淡虛線**（區域色） | 這一群的平均 —— 完全平的 profile 會落在上面 |

### Histogram 出現**兩座山**通常不是雜訊

那多半代表這一群框裡混了兩種材質 —— 也就是**你量的東西不對**，
而那件事比任何平均值都更早該知道。回頭看 ROI 卡把框放在哪。

### Heat map 是一張**示意的格子圖**，不是影像的縮圖

每一格**一樣大**，一欄一個槽，鋪滿整塊圖區 —— 那才是一張 die map 該有的樣子，
兩格也才一眼比得起來。軸上標的是**每一欄代表的位置**（px）。

> 為什麼不照實際比例畫：照實鋪的話每一格畫到與鄰居的中線為止，於是**間距不平均、
> 或少了一格，相鄰兩格的面積就明顯不一樣** —— 而面積不是這張圖在量的東西，
> 一格特別大只會被讀成「這裡比較重要」。

兩個相關的開關在 `Chart settings…` 的 `What is drawn`：

| 那一格 | 做什麼 |
|---|---|
| **Heat map: every cell the same size** | 預設**開**。關掉就回到照實鋪（等比例、每一格畫到中線）—— 要看真實的空間關係時才需要 |
| **Heat map: print the value in each cell** | 每一格裡印出那個數字。**放不下就不印**（印一半的數字比不印糟）|

⚠ **疊在影像上的那一層永遠照實鋪**，不受上面那一格影響 —— 它畫在影像上，
位置必須對得起那張圖。

### 它把**所有區域一起**鋪成一張，而且**色階是共用的**

它畫的不是「這一群」，是**這一片場**：全部區域的框一起決定中線、一起鋪滿，
所以兩個區域擺在各自的位置上，不會互相蓋。

代價是**一條色階給所有區域共用**（圖右下角會寫 `one colour scale across N
regions`）。如果兩個區域量的是不同材質，整張圖會被「兩種材質的差」吃掉 ——
區域**內部**的不均勻反而看不出來。那種時候：

* 要看「這一片哪裡不一樣」→ 就是這張圖，共用色階正是你要的；
* 要比「區域 A 跟區域 B 差多少」→ 看**盒鬚圖**，它的 X 軸就是區域；
* 要單獨看一個區域內部 → 在 `Gray level` 那張卡上只接那一個區域的線。

### Heat map 也**直接疊在影像上**

點 `Write uniformity` 那張卡，**預覽影像上當場就鋪上熱色**（半透明，ROI 框
畫在它上面，左下角一條色條）—— 跟 PEAR 一樣。

那才是這張圖真正的用法：「不均勻在**哪裡**」的答案要對得到晶圓上的位置，
而一張抽掉了影像的圖只剩「有一個角落比較亮」，對不回去。

三件事跟著這個設計走：

* **勾了 `Heat map` 才鋪** —— 畫面上看到的要跟「會寫出去什麼」對得起來；
* **顏色跟寫出去的那張 SVG 逐格相同**（同一支程式碼、同一條色階、同一個鎖定
  範圍）—— 螢幕上調到滿意，檔案就是那個樣子；
* **選到別張卡就不見了** —— 它是那張卡的預覽，不是影像的一個圖層。

## 3. 兩批要比的時候：**先鎖住尺度**

`Chart settings…`（卡上 `Chart look` 那一列的按鈕，或圖的視窗右上角）
→ **`Value scale`**：打開 `Lock the scale`，填 `Bottom` 與 `Top`。

**這是這張卡上唯一非設不可的一格。** auto 縮放在你看**一批**的時候是對的，
兩批擺在一起就會騙人：每一張各自挑各自的範圍，於是

- 兩張直方圖上**一樣高的柱子其實不一樣高**，
- 兩張熱圖上**一樣紅的格子其實不一樣亮**。

而圖上**沒有任何線索**說這件事（軸上的數字要一格一格去讀才發現）。

填法：打開那個開關，兩格都填，而且上界要高過下界。開關關著（預設）就是
auto —— **兩格的數字會留著**，所以比完一批再回到 auto 不必重打。
熱圖鎖住的時候會在色條旁邊寫 `locked`。

## 3.5 圖要長什麼樣：`Chart settings…`

**兩個入口，同一個對話框**：`Write uniformity` 卡上 **`Chart look`** 那一列
的按鈕（那一列旁邊寫著現在改了幾格），或 `Preview charts…` 視窗右上角。
從視窗開的話改完**當場重畫**，按 OK 就寫回卡片的
`Chart look` 那一格 —— 也就是**跟著 recipe 走**：下一次跑、換一台機器跑、
把 recipe 給別人跑，出來的圖長得一模一樣。改錯了 `Ctrl+Z` 撤得掉。

左半是**四張圖共用的長相**，右半是**這一張自己的字**，而右半每一個分頁底下
**當場畫著那張圖** —— 改一格，圖立刻跟著變。從 `Preview charts…` 開的話預覽畫
的是你正在看的那一顆；從卡片直接開、而且還沒跑過的話，預覽用內建的樣本資料
（畫面上會寫出來）。

| 左半 | 管什麼 | 什麼時候會想動 |
|---|---|---|
| **Tick values** | 軸上那些數字的大小／粗體／顏色 | 投影片上看不清楚 → 字級拉到 14–16 |
| **Axis names** | 軸名與圖框的字 | 同上 |
| **Data points** | 每一格框那個記號的半徑與顏色 | 框幾百個 → 半徑調小 |
| **Lines** | 趨勢線、中位線、盒子外框的粗細與顏色 | 投影用 → 粗一點 |
| **Fills** | **柱子／盒子／實心記號的底**：濃度與顏色 | 投影機上 0.45 / 0.18 偏淡 → 濃度拉到 1.5–2 |
| **Name of the value axis** | 值那一軸叫什麼（`glv_mean` → `Gray level`）| 幾乎一定要改 —— 給人看的報告上不該印變數名 |
| **Histogram bars** | 直方圖切幾根柱 | 框很少（<30）→ 調到 10 左右，不然全是空格 |
| **Ticks across / up the side** | 兩軸各幾個刻度 | 刻度數字擠在一起 |
| **A dot for every box** | 畫不畫那些記號 | 框幾百個、點糊成一團 → 關掉 |
| **Whiskers on the box plot** | 盒鬚圖畫不畫鬚 | — |
| **Histogram in %** | 直方圖畫比例而不是次數 | **兩群框數差很多**的時候（不然多的那群永遠比較高） |
| **Value scale** | 見上一節 | 兩批要比的時候 |

> **`Fills` 的「濃度」是一個倍率，不是一個絕對值。** 每一種圖自己那個淡度是
> 設計過的（直方圖的柱 0.45、盒鬚圖的盒子 0.18 —— 盒鬚圖上的墨水本來就多，
> 同樣濃度會糊成一團）。`1` 就是原本的樣子，往上調投影機看得清楚，
> 往下調到 `0` 幾乎只剩外框。

**下面那幾列是一排兩顆膠囊**（跟 GLV 卡同一種），而**兩顆都說得出自己是什麼**
—— 「不打勾會變成什麼樣子」本來要自己在腦裡補一張圖：

| 那一列 | 兩顆 |
|---|---|
| **Markers** | `Hollow`（空心，點多時看得到重疊）／ `Filled`（實心，投影片上明顯）|
| **Marks on the profile** | `No marks`（只留趨勢線）／ `A mark per box` |
| **Box plot** | `Box only` ／ `With whiskers` |
| **Histogram bar height** | `Count`（次數）／ `Share`（比例，兩群框數差很多時用）|
| **Heat map cells** | `True to scale`（照實鋪）／ `Same size`（格子，預設）|
| **Heat map labels** | `Colour only` ／ `Show the value` |
| **Value scale** | `Auto` ／ `Locked`（見上一節）|

**顏色的預設是 `auto`，那不是「沒設定」——** 它是「跟著區域色走」。
每個區域在四張圖上是同一個顏色，那是你認得出誰是誰的方式；填了一個具體的
色碼就會把那件事釘死。要回到 auto 按色塊旁邊那顆 `×`。

右半**一張圖一個分頁**：標題、兩條軸的名字、兩軸各幾個刻度 ——
**但只放那張圖用得到的**。盒鬚圖的 X 軸是類別（一個區域一格），所以它沒有
「橫著幾個刻度」；熱圖兩軸都是影像上的位置，所以它只剩標題。
一格答了也沒用的設定，比沒有那一格更糟。

> **為什麼標題與軸名是每張圖各一份，而字級顏色是共用的**：四張圖的 X 軸是
> 四件不同的事（區域／灰階值／位置／位置），一組共用的名字**一定有三張是
> 錯的**；而「刻度的字要多大」在四張圖上是同一個問題。
>
> 留白＝那張圖自己決定（`the chart decides`）；刻度數那兩格留在
> `same for all` ＝跟左半那一格走。

`Reset to defaults` 是**全部**回預設，包括你現在沒勾的那幾張圖的標題。

## 4. 出事了照這個順序查

| 症狀 | 先看哪裡 |
|---|---|
| **卡片上根本沒有 `How even are the boxes` 這一格** | `Boxes in the region` 還停在 `pooled`。均勻度只在 `each box` 下成立 |
| **資料夾是空的，一個檔都沒有** | 同上。這張卡會在跑完之後講一句「Gray level 要設成 each box」 |
| **`slope_x` 那一欄整欄是 0.000** | 你的圖真的很平；或是有人把單位從「每 100 px」改掉了（見 §1）|
| **斜率那一格根本不存在** | 只有一格框，或所有框的 X 都一樣（一整欄）。那是「問不出來」不是「很平」|
| **Position profile 上一格框一個轉折，鋸齒狀** | 框的中心差幾個 px 沒被當成同一欄。這件事本來是自動的（見下）—— 出現的話代表你的框真的是散開的，不是一個網格 |
| **Heat map 碎成一堆細條** | 同上 |
| **跑完了但找不到資料夾** | 你按的是 `Run trial` —— 它**刻意不寫檔**。用右邊箭頭的 `Run all & write`（§5）|
| **資料夾在，但不是我要的地方** | `Write to` 填的是相對路徑，落在啟動 Studio 的那個資料夾旁邊。填完整路徑 |
| **有圖但沒有 CSV** | 少一張 `Write report`（§0 第 5 步）|
| **四張圖都是空的** | `Which number to plot` 打錯了，或上游還在 `pooled`。**跑之前畫布上就會有黃字講這件事** —— 卡片上有驚嘆號就先讀它 |
| **載入大圖之後卡很久** | 7680×7680 疊 Golden Cell 約 17 秒，會有進度條與取消鈕。沒有進度條代表那張圖小到不用等 |
| **兩張圖比起來怪怪的** | 尺度沒鎖（§3）|
| **Histogram 兩座山** | 框放錯位置，混到兩種材質（§2）|
| **`cv_pct` 大得離譜** | 先看 Heat map 有沒有一格特別紅 —— 一顆髒點就能把它拉走。`glv_boxes_over_k` 說得出「有幾格越線」，那才分得出「一顆髒點」與「整片都不對」|

> **關於「差幾個 px 算同一欄」**：手放的框、次像素定位出來的框、
> 從 layout label 拆出來的框，中心都不是整數。程式會從資料本身量出一個容差
> （相鄰間距排序之後那個**階梯**落在哪），把同一欄的框收在一起。
> 真的散開的分布**不會**被合併 —— 那不是抖動，合併它等於把資料改掉。

## 5. 跑完之後結果在哪

### ⚠ `Run trial` **不會寫任何檔案**

工具列那顆最大的鈕是 **`Run trial`** —— 跑前幾顆、只更新畫面，**刻意不寫檔**
（每拖一下門檻就覆寫一次檔案是不可逆的）。

要拿到檔案請按它**右邊的箭頭** → **`Run all & write`**（Results 視窗裡也有
同名的那一顆）。試跑完狀態列會提醒你這件事。

### 三個地方

| 我要看什麼 | 去哪 | 什麼時候 |
|---|---|---|
| **四張圖**（確認設定對不對）| 點 `Write uniformity` 卡 → `Preview charts…` | **馬上**，不用跑 |
| **四張圖**（放進報告）| `Write to` 那個資料夾 | `Run all & write` 之後 |
| **數字**（cv%、斜率）| 點 `Gray level` 卡，特徵表 | 跑一次預覽之後 |
| **數字**（進 Excel）| 同一個資料夾的 `defects.csv` | 要有 `Write report` 那張卡 |

### 資料夾裡會有什麼

一顆 defect 寫五個檔，外加整批一份 CSV：

```
index.html                ← 好幾顆才有：每一顆一列，帶 CV% 讓你挑該點哪一個
<名字>.html               ← 一顆的答案：四張圖 ＋ 上方一張數字表
<名字>-box.svg            ← 一張圖一個檔（丟進 Word/PPT 用，向量不會糊）
<名字>-histogram.svg
<名字>-profile.svg
<名字>-map.svg
defects.csv               ← 每一顆每一欄（`Write report` 產的）
recipe.json               ← 這次的設定，之後重現得出來
```

`<名字>` 是你那張圖的檔名。**只有一顆的時候不寫 `index.html`** —— 那一顆的
頁面本來就是答案。

### `<名字>.html` 上方那張表

```
region   number      CV %   range   range %   left→right   top→bottom   boxes
                                              /100 px      /100 px
cells    glv_mean    0.25     -        -        0.13         0.03        100
```

沒勾的那幾格印 `-`（不是 0）。**這些數字跟 `defects.csv` 裡是同一份** ——
報表這邊不重算，不然同一顆會出現兩個 CV%。

---

## 6. 這張卡**不下判斷**

出貨的 `one-image-uniformity` recipe 的判定樹只分兩類：
**量不到**（bin 9）與**量到了**（bin 0）。裡面沒有任何一個門檻說一片場好或不好。

那是刻意的：那個數字是你的，而且每一層不一樣。要門檻的話自己加進判定樹
—— 例如 `glv_mean_cv_pct > 2` 就分一類出來。

## 7. 它跟 `Write report` 的盒鬚圖差在哪

兩張卡都會畫盒鬚圖，而且長得一模一樣。差別只有一個，但那個差別就是全部：

| | 一個盒子是 | 一個點是 |
|---|---|---|
| **Write report** | 判定樹的一片葉子 | **一顆 defect**（整批的圖）|
| **Write uniformity** | 一個區域 | **一格框**（一張圖之內）|

一批 400 顆的分類結果 → `Write report`。
一張圖上幾百個框均不均勻 → `Write uniformity`。

**兩張圖現在吃同一種設定。** `Write report` 也有一格 `Chart look`，開的是同一個
`Chart settings…` 編輯器 —— 所以同一份投影片裡的兩張盒鬚圖可以調成一樣的字級、
線寬、刻度數與鎖定範圍。以前只有 `Write uniformity` 吃得到，於是兩張並排時長得
不一樣，而畫面上沒有任何線索說為什麼。

⚠ **兩張卡各存各的一份**（各自的 `Chart look` 那一格）—— 它們可以不一樣，
只是現在**做得到**一樣。

⚠ `Write report` 那一格**沒有「每張圖自己的字」**（標題、軸名）：它一次畫好幾張
盒鬚圖（一個數字一張），一組共用的標題會同時套到五張上。那一頁上每張圖的標題
就是**那個數字的名字**。
